# 로드맵

## M1 — 기반 구조

Android 전용 Flutter 앱 진입 구조, 모듈 폴더, 요구사항·설계·라이선스 문서를 준비한다.

## M2 — 스캔 세션

스캔 작업과 페이지 상태를 관리하는 도메인 모델 및 로컬 저장 구조를 설계한다.

## M3 — 캡처와 원본 보관

카메라 촬영 가이드, 권한 처리, 원본 이미지 보관을 구현한다.

## M4 — 온디바이스 문서 처리

라이선스 검토를 마친 오픈소스 구성요소로 검출·원근·곡면·화질 보정 파이프라인을 구현한다.

## M5 — 편집과 내보내기

페이지 편집, OCR 제목 추천, PDF 생성 및 저장 위치 선택을 구현한다.
